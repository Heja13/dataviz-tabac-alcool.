Boire tous les jours : hommes et femmes

Hommes

Femmes

Ce qu'on observe. Entre 2000 et 2021, la part de personnes qui boivent tous les jours diminue fortement dans toutes les régions, chez les hommes comme chez les femmes. En 2000, elle dépassait 30 % chez les hommes dans plusieurs régions (jusqu'à 39 % en Nouvelle-Aquitaine) ; en 2021, elle ne dépasse plus 16 % (Occitanie). Les hommes sont plus concernés que les femmes dans chaque région.

Comment lire. La couleur indique la part de personnes qui boivent tous les jours, du jaune (peu) au rouge foncé (beaucoup). Les deux cartes ont les mêmes classes de couleurs, donc on peut les comparer. Les classes sont plus étroites pour les petites valeurs, afin que les différences entre régions restent visibles chez les femmes. Choisissez une année avec le menu et passez la souris sur une région pour lire sa valeur. Une région grise n'a pas de donnée.

Source : Santé publique France (Baromètre), via Odissé. Taux standardisés sur l'âge, personnes de 18 à 75 ans. La Corse n'est pas couverte. Les régions d'outre-mer ne sont disponibles qu'en 2021 : elles figurent dans les cases sous chaque carte. Contours : France GeoJSON, d'après l'IGN.
